GUÍA DE USO

Comprende cada cálculo.

Estadística

  1. Pega hasta 1.000 números. Separa con espacios, punto y coma o saltos de línea.
  2. La coma se interpreta como decimal: 1,5; 2,5 representa dos números. Para tres enteros escribe 1; 2; 3.
  3. Elige muestra (divisor n − 1) o población (divisor n), según el ejercicio.
  4. Calcula y revisa los pasos. Despliega los datos para ver las desviaciones de las primeras 100 filas; todas participan en el cálculo.
  5. Introduce tu respuesta y una tolerancia absoluta para comprobarla. Un resultado aceptado tiene |respuesta − resultado| ≤ tolerancia.

Unidades

  1. Selecciona el valor y unidad de origen. La unidad de destino solo ofrece magnitudes compatibles.
  2. Convierte y revisa el paso por la unidad base. Las temperaturas usan kelvin y no admiten valores bajo cero absoluto.
  3. Compara tu respuesta con el comprobador de conversión.

Respaldo y privacidad

El trabajo se conserva en el navegador cuando este lo permite. No se sincroniza entre equipos. Exporta JSON y usa Importar JSON en el otro navegador. La importación requiere confirmar la sustitución. Borrar datos elimina el guardado de esta herramienta; los archivos descargados se administran por separado.

Alcance

Estadística descriptiva de una variable, conversión de longitud, masa, tiempo y temperatura. No interpreta problemas abiertos, no es un chatbot de IA y no certifica decisiones profesionales. Evita datos personales o clínicos identificables. Los decimales mostrados se redondean a diez cifras significativas; el comprobador usa el valor calculado sin ese redondeo.
