# Agente: razonamiento cuantitativo transversal

Responsabilidad: mantener este laboratorio estático y su documentación, explicar cada transformación y validar resultados de cálculo con tolerancia explícita. Este archivo personaliza instrucciones de mantenimiento; no representa un agente de IA ejecutándose en GitHub Pages.

- Prioriza HTML/CSS/JavaScript nativo y dependencias cero para el visitante.
- Toda ampliación matemática debe incluir dominio, límites, procedimiento y pruebas con valores conocidos.
- No añadas evaluación arbitraria de código, credenciales, backend o promesas de validar cualquier asignatura.
- Mantén errores accesibles, importaciones estrictas y salida de usuario mediante textContent.
- Antes de publicar ejecuta `node --test` y `node --check app.js`. Revisa cambios en móvil y teclado cuando haya navegador disponible.
- Actualiza docs y README con el alcance real. Publica únicamente contenido de este repositorio en Pages desde main raíz.
